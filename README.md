# Personal Profile Page

A beginner-level personal profile webpage built with semantic HTML5 and CSS.

## Features

* Semantic HTML5 elements:

  * `header`
  * `nav`
  * `main`
  * `section`
  * `footer`
* Correct heading hierarchy with one `h1` and nested `h2`/`h3` headings
* Profile image with meaningful `alt` text
* One ordered list
* One unordered list
* Internal page anchor link
* External link
* Separate CSS file for:

  * Fonts
  * Colors
  * Spacing
* Navigation sections:

  * Home
  * Courses
  * Certified
  * Profile

## Technologies

* HTML5
* CSS3

## Project Structure

```text
Personal-Profile-Lavaloon/
```

## How to Run

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.
